# Phase 02 — Threat model

Model external Dolev–Yao control of the network, malicious/revoked CAVs, and
Byzantine consensus participants. Use ML-KEM/ML-DSA because a quantum-capable
adversary threatens classical public-key assumptions.

**Complete when:** replay, forgery, Sybil, false-position, DoS, and collusion
experiments each have a stated detection/mitigation path.
